# Reconnaissance de Chats et de Chiens

Projet de Machine Learning permettant de classifier des images de chats et de chiens.

## Technologies

* Python
* TensorFlow
* MobileNetV2
* Google Colab
* Gradio

## Description

Le modèle utilise le Transfer Learning avec MobileNetV2 pour reconnaître les chats et les chiens à partir d'images. Une interface simple a été réalisée avec Gradio pour tester les prédictions.

## Remarque

Les résultats sont satisfaisants, mais le modèle n'est pas encore parfait et nécessite des améliorations pour augmenter sa précision.
